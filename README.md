# Personal Portfolio Website Redesign

This repository contains the redesigned personal portfolio website built using semantic HTML5, CSS3, and version-controlled using Git and GitHub.

## 🚀 Features
- **Semantic HTML5 Structure:** Built using `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>` for maximum accessibility and visual hierarchy.
- **Modern Responsive Design:** Features a dark linear-gradient background, sticky navigation bar, styled interactive tables, and fluid typography (`clamp()`).
- **Clean Project Structure:** Modular file organization with an external stylesheet (`style.css`) and local media assets (`Khalid.jpeg`).

## 🛠️ Built With
- **HTML5** - Page structure and semantic layout
- **CSS3** - Custom styling, visual styling, linear gradients, and responsive table formatting
- **Git & GitHub** - Branch management (`feature/redesign` -> `main`) and version control

## 📝 Written Reflection
During this redesign, my primary objective was to improve both visual aesthetics and semantic code structure. Transitioning from inline styles to a centralized external stylesheet streamlined the development process significantly.

Working with Git branches (`feature/redesign`) provided a safe environment to test responsive breakpoints without affecting the initial `main` branch code. Resolving unrelated branch histories strengthened my understanding of command-line Git workflows, merging, and remote repository syncing via Pull Requests. Future improvements include adding interactive JavaScript project showcases and automated contact form processing.
